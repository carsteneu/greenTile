Coming from Windows

FancyZones, on Linux Mint.

On Windows you drew zones once, held Shift while dragging, and every window had a home. Linux Mint has nothing called FancyZones. It has most of the pieces, though, and the missing ones are a different way of thinking rather than a missing feature.

greenTile is that missing part on Cinnamon: the layout exists before the windows do, every window lands in it by itself, and the rest of the desktop stays as it is.

What you are leaving behind.

FancyZones is part of Microsoft PowerToys, the open source toolbox for Windows. It has had years to grow, and the list is longer than most people remember using:

  • Layouts with zonesBuilt from templates (columns, rows, grid, priority) or drawn by hand in two editor styles: Grid, which splits and merges cells, and Canvas, where zones may overlap.
  • A layout per monitorDifferent monitors can run different layouts, and a default layout applies when the display setup changes: one for horizontal, one for vertical orientation.
  • Drop a window into a zoneHold Shift while dragging and the zones appear; the zone under the pointer lights up. Holding Ctrl while dragging spreads one window over several zones.
  • Layout hotkeysWinCtrlAlt+a number applies a saved layout to the active screen. Every layout can carry its own hotkey.
  • New windows go where they belongMove newly created windows to the last known zone puts a new window back where that application sat before.
  • Rules that surviveExcluded applications, gaps around zones, and keep windows in their zones when the screen resolution changes.

The feature that carries the whole idea is the last one of the drop-a-window group: the zone is not just a picture, it is a target with memory. Everything you rebuild on Linux has to reproduce that memory one way or another.

What Cinnamon does on its own.

No extension needed. These are the defaults on Linux Mint 22 with Cinnamon 6.x, taken from Cinnamon's own settings schemas.

  • Halves, from the keyboardSuper+← pushes the focused window into the left half, Super+→ into the right one, Super+↑ and Super+↓ into the top and bottom half.
  • Quarters, by combining themPush left, then push up: the window takes the upper left quarter. Pushing in the opposite direction untiles it again. Cinnamon's window manager Muffin supports this; the keyboard reference in the settings just does not mention it.
  • Halves and maximise, with the mouseDrop a window on a vertical screen edge and it covers that half. Drop it on the top edge and it maximises. This edge tiling is on by default.
  • MaximiseAlt+F10, or a double click on the title bar.
  • WorkspacesFour of them by default (up to 36). CtrlAlt+←/→ switches, CtrlAltShift+←/→ takes the focused window along.
  • Hot corners, switched offThe four screen corners can run Expo, Scale or show the desktop, but every one of them ships disabled. If you miss the Windows corner gestures, this is where to switch them on.

Read that list again and you will notice what it has in common. Every entry acts on the window you are pointing at or focusing, and every one of them is a single, finished move: push this one left, drop that one on an edge, send the third one to another workspace. Nothing on the list can look at the screen and decide. Nothing on it can hold a shape in mind, and nothing remembers what you built yesterday.

That is not a criticism, it is a design decision. Cinnamon's window management is built to stay predictable, and predictable means: only what you asked for, only when you ask. The price is that the arranging is yours to do every single time. That is exactly the part FancyZones automated for you, and the part greenTile takes over here.

The mapping.

Here is every FancyZones idea worth keeping, and what it becomes on Cinnamon. The drawings show the result: a preset column is not a zone, and it is worth seeing the difference before you start painting.

  1. PowerToys: a layout of zones

    A preset instead of zones

    In FancyZones you design a layout of zones, per monitor, and pick which application sits where. Here the equivalent is a preset: columns painted on a 6 × 4 grid, each column holding one window or a stack of them, widths free. A preset belongs to a monitor and a workspace, so the same screen can be laid out differently depending on where you are.

  2. PowerToys: the layout editor

    The preset panel

    WinShift+` opens the editor on Windows. SuperCtrlP opens the preset panel here, on the monitor of the focused window. Sixteen editable starters are already in it, so you rarely start from an empty grid, and the panel shows a live preview of what each card would do with the windows you have open right now.

  3. PowerToys: drop into a zone

    Drop into a cell, or split a neighbour

    Shift and drag on Windows, then release over the highlighted zone. Here you drag a window over another one: a translucent preview shows the new column, the stack or the row before you let go, and the neighbours move up to fill what you left. The preview is doing the job the highlight does in FancyZones: telling you the result before it happens.

  4. PowerToys: layout hotkeys

    Columns on a key

    FancyZones gives every saved layout a hotkey. Here presets are applied from the panel or by assignment, and the column hotkeys SuperCtrl+3 and SuperCtrl+6 re-draw the screen as equal columns on the spot, useful when you want a quick three-way split without touching the presets.

  5. PowerToys: new windows remember their zone

    Auto mode

    This is the feature to port first, and greenTile answers it for the whole layout rather than per application. With auto mode on for a workspace (SuperCtrlA), a window that opens is fitted into the preset 300 ms later. Close one and the others grow into the space. No dragging, no remembering where things were.

  6. PowerToys: layouts survive a resolution change

    Assignments survive a replug

    FancyZones keeps windows in their zones when the resolution changes. Here the layout itself is remembered: a preset is assigned to a monitor by its hardware identity, so unplugging the big screen, plugging it back in or turning it off for the afternoon brings the right layout back. After a Cinnamon restart the windows return in the order you left them, so the arrangement rebuilds the same way.

  7. PowerToys: excluded applications

    The never tile list

    PowerToys takes a list of application names that should never be snapped. The same exists here and is a bit more precise: a never tile list that matches window class, title or app id, filled either by hand or from a picker that lists your installed applications, flatpaks included. Dialogs and fixed-size windows stay out on their own, and SuperG lifts a single window out of the grid without a rule.

  8. PowerToys: space around zones

    Gaps between windows

    A setting in PowerToys, a slider in the preset panel here: 0 to 48 px between windows. Only the shared edges move in; the outer edges of the layout stay flush with the screen, which is the part that makes a tiled desktop look deliberate instead of accidental. The value is applied as insets, so a gap can never push a window off its monitor.

  9. PowerToys: one window over several zones

    Columns that span

    FancyZones lets you hold Ctrl while dragging to spread a window over two adjacent zones. greenTile turns that around: the width belongs to the layout, not to the drop. Drag the handle between two painted columns to merge them into one wide column (1 : 2 : 1, 25 / 50 / 25, whatever your screen wants), and the handle inside a wide column splits it again.

Rebuilding your layouts.

Half an hour, if you had three or four layouts on Windows. Start with the one you used most, live with it for a day, then do the next.

  1. Install greenTile from the release zip, restart Cinnamon, switch it on in the Extensions manager. Nothing is replaced or removed; the built-in keys keep working.
  2. Paint your most used layout in the preset panel (SuperCtrlP): columns on the 6 × 4 grid, the handle between two columns to merge them into a wide one. A layout like one wide column left, two stacked right is three clicks, and the preview under each card shows what a click does with the windows you have open.
  3. Assign it to the monitor and workspace you want it on. Then switch to the next workspace and set that one up too; the panel always edits the monitor and workspace you are on right now.
  4. Turn on auto mode (SuperCtrlA) on the workspaces that should look after themselves. Leave one off and it stays a free surface, which is often what you want on a workspace you use for one big window.
  5. Fill the never tile list with the apps that should stay out, the same way you excluded applications in PowerToys. Dialogs and fixed-size windows are already excluded for you.
  6. Try the two habits that replace dragging: SuperG floats a window and pressing it again tiles it back, and SuperCtrl+arrow swaps the focused window with its neighbour, and keeps going across monitors and workspaces if you hold the rhythm.

What you gain.

The idea of FancyZones, kept, with the dragging done for you.

Set up once

The layout replaces the drag

Instead of drawing zones and then dragging each window into one, you paint the layout once (columns, their widths, the stacks inside them) and assign it to a monitor and a workspace. Placement is done for you from then on.

The whole layout

Auto mode, for every window

PowerToys puts a window back where that application last sat. Here the arrangement decides instead: with auto mode on, a window that opens is fitted into the layout, whatever the application is.

The details

Gaps, rules, wide columns

0–48 px between windows as insets that never push one off the screen, a never tile list matched by window class, title or app id and filled from a picker that includes flatpaks, and columns you merge into one wide one or split again.

Still Cinnamon

Nothing about the desktop changes

Panel, menu, applets, themes and every built-in key stay exactly as they are. greenTile adds the missing piece; it never asks you to move to a different desktop.

What has no equivalent.

Not everything comes across, and it is worth knowing which parts before you start:

  • Overlapping zones. FancyZones Canvas allows zones that overlap and windows that share space. Here a layout is a grid: cells share edges, they do not stack on top of each other. A wide column is how you make room, not an overlapping zone.
  • Zones that span monitors. FancyZones can treat all monitors as one large screen. greenTile works per monitor: dragging a window to the other screen retiles both, but there is no single layout stretching across both displays.
  • Zone-based keyboard navigation. Stepping from zone to zone with Win+arrows has no mirror image; the nearest things are swapping with the neighbour (SuperCtrl+arrow) or giving the workspace a different preset.
  • Per-application zone memory. PowerToys remembers the zone a specific application last sat in. Here the layout decides, not the application: every window of a workspace is fitted into the same arrangement, which is simpler to predict and costs you the "Editor always on the right" habit. The related Cinnamon extension auto-move-windows covers that part separately, by putting applications on their own workspace.
  • Windows-only muscle memory. The Win key is Super here, and Cinnamon keeps its own keys for workspaces. Ten keys in total are documented on the home page.

The idea you keep is the one that mattered: you decide once how the screen is divided, and afterwards the windows obey.
