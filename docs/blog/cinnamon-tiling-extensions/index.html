The field, honestly

Tiling extensions for Cinnamon.

The Cinnamon Spices catalogue lists 44 extensions. Exactly one of them tiles windows. Outside the catalogue there are two more projects worth knowing about. That is the entire field for window tiling on Cinnamon — here it is, with what each project is good for.

The two tiling extensions How to choose

44 extensions, one tiler.

Cinnamon installs extensions from the Spices catalogue, reachable in System Settings → Extensions → Download. We went through all 44 entries and searched for anything that touches window placement. One extension does: gTile.

These are the neighbours — useful, but they solve a different problem:

The third column is worth a look in general: a good part of the catalogue was written before Cinnamon 6, and its entries still declare support for 4.x or 5.x. Cinnamon runs them anyway in most cases, but nobody has tested them recently.

The two tiling extensions.

They answer different questions. Both are free software under the GPL v3, both can be installed side by side, and only one of them should be enabled at a time.

In the catalogue · since forever

gTile

  • You place a window. A grid opens over the focused window, you select an area — with the mouse, with the arrow keys and Shift, or by typing two tile labels — and confirm. The other windows do not move.
  • Four grids on the number keys, plus two buttons that arrange everything once: Auto tile main and list and Auto tile two lists.
  • Version 2.2.1 in the catalogue, multiversion, with separate code paths for Cinnamon 3.8 and 5.4 and support declared from 3.6 on.
  • Written by vibou for GNOME Shell, ported to Cinnamon by shuairan, maintained by the community in Linux Mint's spices repository. Its last functional change there is from September 2025; since then only translations.
  • Installed in one click from the Extensions manager — the lowest-friction way to try tiling on Cinnamon.
Not in the catalogue · installs from a zip

greenTile

  • The layout exists first. A preset is painted on a 6 × 4 grid and assigned to a monitor and a workspace. Windows that open, close or return are fitted into it.
  • Auto mode per workspace, sixteen editable starter presets, columns that span, gaps from 0 to 48 px, a never tile list, drag-to-split.
  • A fork of gTile 2.2.1: the extension skeleton and the translation sources come from gTile, the classic grid was replaced by the preset and auto model. Less than 1 % of the runtime code is untouched gTile code, measured on 2.2.0.
  • Installs from a release zip with a script, so it does not appear in the Extensions manager's download list yet.
  • Tested on Linux Mint 21.3 to 22.3 (Cinnamon 6.0.4 to 6.6) with X11; first tests on Wayland pass for auto tiling, retiling and the preset panel.

The detailed comparison — per monitor and workspace, gaps, keys, what happens when a window closes — is in greenTile vs gTile.

Outside the catalogue.

Extensions do not have to live in the catalogue. Two kinds of projects exist out there:

  • Cinnamon Automatic Tiling (perlgui, on GitHub, version 0.3) — "Automatic window tiling for the Linux Mint Cinnamon desktop environment". It requires Linux Mint 22.x with Cinnamon 6.6.x and says about itself that it is functional but that some behaviour may be unstable or incomplete. It brings its own installer and supports drag-and-drop tile swapping. Worth a look if you want to compare a second approach; expect to install it by hand and to keep an eye on it.
  • Smaller side projects. A GitHub search for "cinnamon tiling" turns up 19 repositories in total, most of them experiments, personal setups or abandoned sketches. There is no third project with real use behind it.

That is the whole market. On a desktop that has a catalogue with 44 maintained extensions, window tiling is a niche with one long-standing entry — which is exactly why greenTile exists.

How to choose.

Three questions, three answers.

  • Do you want to place each window yourself?Then you want a grid you open and select in. That is gTile, and it has been doing it well for a decade.
  • Do you want the workspace to arrange itself?Then the layout has to exist before the windows do, which is what greenTile's presets and auto mode are for.
  • Do you want neither?Cinnamon's built-in halves, quarters and edge snapping may be all you need. Here is what the desktop does on its own.

Do not enable two tiling extensions at the same time. gTile and greenTile claim some of the same keys — SuperG among them — and the result is windows fighting over the same pixel. Disable one before you try the other.
