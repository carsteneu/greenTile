A gTile alternative for Cinnamon

greenTile vs gTile.

Both are tiling extensions for the Cinnamon desktop, and greenTile started as a fork of gTile. They answer different questions, though: gTile places the window you point at, greenTile arranges a whole workspace by itself. Here is how they compare.

Compare them Switching from gTile

gTile: you place a window

Open the grid over the focused window, select an area of cells with the mouse or the arrow keys, confirm, and the window moves there. The other windows stay where they are.

greenTile: windows place themselves

Turn on auto mode or assign a preset to a monitor and workspace. Every window that opens, closes, minimizes or comes back is fitted into that layout, without opening anything.

Switching from gTile.

Both can stay installed, but do not enable them together: they claim some of the same keys, SuperG among them.

  1. Disable gTile in System Settings → Extensions.
  2. Install greenTile from the release zip, restart Cinnamon and enable it.
  3. Press SuperCtrlA on a workspace. Its windows tile, and new ones join on their own from now on.
  4. Rebuild your grids as presets in the preset panel (SuperCtrlP). A preset is a set of columns painted on a 6 × 4 grid, each holding one window or a stack. For Auto tile main and list, the starter Left main + stacks keeps a main window on the left and stacks the rest beside it. Drag a border to change the widths; greenTile remembers them per window count.
  5. Learn one new key: in greenTile, SuperG does not open a grid. It lets the focused window float, and pressing it again tiles it again.

Where greenTile comes from.

greenTile is a fork of gTile 2.2.1, which was written by vibou for GNOME Shell and ported to Cinnamon by shuairan. The extension skeleton and the translation sources come from gTile; the classic grid was removed and the preset and auto model built in its place. Nearly unchanged code inherited from gTile is less than 1 % of greenTile's runtime code, measured on version 2.2.0 as described in the README. Both are free software under the GPL v3.
